# PREACT World Intelligence System — Product North Star and Milestones

## Product definition

PREACT evolves into a **World Intelligence System**: an interactive political, historical, geographic and sociological atlas of the world built on a temporal knowledge graph, with a separate probabilistic forecasting layer.

The forecasting engine remains important, but it is no longer the product's primary entry point. The primary experience is the world itself.

## Home experience

The default home is a globe-first explorer.

A user selects a country and PREACT opens a deep country intelligence profile while the rest of the world is recoloured by its relationship to the selected country.

The country profile covers:

- current constitutional and political system;
- head of state, head of government, cabinet/coalition and opposition;
- legislature, electoral system, courts, territorial structure and checks and balances;
- democracy/governance dimensions from sourced indicators rather than one opaque score;
- economic and demographic fundamentals;
- sociological structure: age, education, inequality, urbanisation, migration, religion/language where supported by evidence;
- a historical timeline from state formation to today, with materially deeper twentieth-century coverage;
- current and historical interstate relations;
- current events and material changes;
- forecasts and scenarios clearly separated from observed facts.

## Relationship layer

Relationships are multidimensional. PREACT must not reduce a pair of countries to an unsupported "friend/enemy" label.

Supported relationship dimensions include:

- formal alliance / treaty membership;
- diplomatic cooperation or dispute;
- trade and economic dependence;
- sanctions;
- territorial disputes;
- military incidents;
- armed conflict;
- voting / institutional alignment when supported;
- historical relation;
- news/event interaction signals.

Each relationship edge is temporal and sourced:

```text
subject
object
relation_type
valid_from
valid_to
known_at
source
source_ref
confidence
attributes
```

The UI may derive an alignment/tension summary, but the underlying evidence must always be inspectable.

## Temporal globe

The globe has a time control.

Moving the selected date changes the visible world state using point-in-time data:

- governments and office holders;
- alliances and treaties;
- conflicts;
- sanctions;
- relevant social/economic indicators;
- historical events;
- eventually historical borders where licensed geometry is available.

The system distinguishes **valid time** from **knowledge time** so historical replay cannot use evidence that became known later.

## Knowledge classes

PREACT exposes four visually distinct semantic classes:

1. **FACT** — directly sourced current or historical claims.
2. **INTERPRETATION** — sourced or model-assisted analysis.
3. **FORECAST** — probabilistic prediction generated by PREACT.
4. **COUNTERFACTUAL** — output conditional on an explicit scenario/intervention.

Narrative descriptions are generated views over versioned facts and must never silently turn inference into fact.

## Autonomous World Knowledge maintenance

PREACT must maintain the World Knowledge Layer autonomously.

Canonical pipeline:

```text
24/7 sources
 -> candidate event
 -> entity resolution
 -> claim extraction
 -> source/provenance capture
 -> corroboration
 -> materiality classification
 -> temporal consistency checks
 -> promotion decision
 -> append new world-state version
 -> close superseded version
 -> queue affected narrative sections for regeneration
 -> expose change to UI and forecasting engine
```

A single article does not automatically rewrite a country page.

### Promotion rules

Structured facts may be promoted automatically only when evidence satisfies a fail-closed policy, for example:

- at least one authoritative primary/official source; or
- at least two independent source groups;
- confidence threshold met;
- subject, field, value and effective date resolved;
- no unresolved temporal contradiction.

Interpretations are stored separately and cannot overwrite facts.

Forecasts never update factual country descriptions.

### Example: government change

PREACT does not overwrite:

```text
Prime minister = Person A
```

with Person B.

It closes one assertion and appends another:

```text
Person A: valid_from=T0, valid_to=T1
Person B: valid_from=T1, valid_to=NULL
```

Both retain the time PREACT learned the information and their source evidence.

### Narrative regeneration

Descriptions such as "Political system today" are materialized from structured knowledge.

A promoted material fact can create a narrative regeneration job for affected sections, for example:

- current government;
- political system;
- foreign relations;
- conflict/security;
- recent history.

The narrative generator must cite its supporting assertions and preserve previous rendered versions.

## Event-to-history lifecycle

Current events can mature into historical timeline entries.

PREACT periodically re-evaluates event importance based on observable consequences such as:

- duration;
- institutional change;
- casualties / geographic spread where applicable;
- number of affected countries;
- treaty/legal changes;
- persistence in high-quality later sources.

This avoids deciding on day one which headlines will become historically important.

## Milestones

### M0 — Temporal foundation — existing / continue hardening

- canonical entities;
- `valid_time` + `known_time`;
- source snapshots and provenance;
- replay-safe queries;
- temporal relation store;
- source/licence registry.

### M1 — World Explorer foundation — existing / expand

- country catalogue;
- selectable world map;
- current socioeconomic indicators;
- GDELT relationship signals;
- documented structural relations;
- country profile shell.

### M2 — Autonomous World Knowledge v1 — START NOW

- source-agnostic knowledge update candidate contract;
- explicit FACT / INTERPRETATION / FORECAST separation;
- fail-closed corroboration/promotion policy;
- immutable candidate/evidence ledger;
- versioned current-state assertions;
- automatic closure of superseded assertions;
- narrative regeneration queue;
- tests for provenance and temporal mutation.

### M3 — Political System Knowledge

For every country:

- constitutional form;
- state structure;
- executive selection/removal;
- legislature;
- electoral rules;
- head of state / government;
- governing coalition and opposition;
- judiciary / constitutional review;
- territorial autonomy;
- governance/democracy dimensions with dated sources.

The output includes both structured fields and a deep explanatory narrative.

### M4 — Historical Timeline

- state-formation chronology;
- event hierarchy by era;
- materially deeper twentieth-century coverage;
- event pages with causes, actors, consequences and related states;
- event-to-history maturation;
- point-in-time historical navigation.

### M5 — Sociological Atlas

- demography;
- education;
- urbanisation;
- labour;
- inequality;
- migration;
- language/religion where reliable;
- public opinion where comparable survey evidence exists;
- long-run series and cross-country comparison.

### M6 — Relationship Graph 2.0

- formal alliance;
- diplomacy;
- trade dependence;
- sanctions;
- disputes;
- conflict;
- event-derived interaction trends;
- evidence-backed alignment/tension summaries;
- relationship pages and historical evolution.

### M7 — Globe-first professional frontend

Move the definitive World Explorer from a Streamlit prototype to a dedicated WebGL frontend.

Target capabilities:

- full-screen 3D globe;
- country click/hover;
- relationship arcs and thematic layers;
- side-panel country intelligence;
- temporal slider;
- compare mode;
- event playback;
- desktop/tablet responsive experience.

The backend remains FastAPI and the temporal knowledge layer remains independent from rendering technology.

### M8 — Autonomous narrative and change intelligence

- regenerate affected country/relationship descriptions after material verified changes;
- show "what changed and why";
- maintain narrative version history;
- confidence/provenance inspection;
- event importance re-evaluation;
- material-change alerts.

### M9 — Forecast integration

The existing PREACT prediction modules consume the same point-in-time world state.

Forecasts remain separate objects with:

- model/version;
- prediction time;
- horizon;
- probability/uncertainty;
- evidence/features available at prediction time;
- later outcome and calibration result.

### M10 — Historical Replay and Scenario World

- move the globe to a historical cutoff;
- reconstruct what PREACT could know then;
- run forecast from that cutoff;
- compare with realised outcomes;
- apply explicit counterfactual shocks;
- inspect propagation through country and relationship graphs.

## Architectural invariant

The product must always preserve:

```text
OBSERVED WORLD != INTERPRETATION != FORECAST != COUNTERFACTUAL
```

The globe can display all four, but never without making the distinction visible.

## End state

PREACT becomes a continuously maintained, point-in-time memory of the world.

Its durable asset is not only knowing what the world looks like now, but retaining a structured record of **how political systems, societies, alliances, conflicts and narratives changed through time**, together with the evidence that caused each update.
